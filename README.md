# Отделка Минск — одностраничный сайт

Адрес: https://pallsmi.github.io/otdelka-minsk/ (белорусская версия — `/be/`).

Статический сайт на двух языках (русский — корень, белорусский — `/be/`) для бригады, которая делает штукатурные, малярные и отделочные работы в Минске. Без фреймворков и сборщиков: готовые HTML, CSS и JS лежат в корне и сразу работают на GitHub Pages.

## Структура

```
index.html            русская версия (собирается из src/)
be/index.html         белорусская версия
privacy.html, be/privacy.html   политика конфиденциальности
404.html              страница «не найдено» для GitHub Pages
css/style.css         стили (mobile-first)
js/main.js            меню, фильтр работ, просмотр фото/видео, форма
assets/img/           фото и кадры из видео в WebP (несколько размеров)
assets/video/         видео в MP4 без звука, грузятся только по нажатию
assets/fonts/         шрифты Unbounded и Onest (лицензия SIL OFL, файлы LICENSE-*)
src/                  исходники: данные, тексты, шаблоны, скрипт сборки
```

HTML-файлы в корне генерируются. Править нужно `src/`, затем пересобрать.

## Как поменять контакты и тексты

1. Контакты, название, адрес сайта, подключение формы — `src/site.json`.
   Пустое поле = на сайте видна жёлтая пунктирная заглушка.
2. Тексты — `src/content/ru.json` и `src/content/be.json`.
3. Пересобрать:

```bash
pip install jinja2
python3 src/build.py
```

Проверить локально: `python3 -m http.server 8000` и открыть http://localhost:8000.

## Публикация на GitHub Pages (бесплатно)

1. Создать публичный репозиторий на github.com, например `otdelka-minsk`.
2. Загрузить содержимое этой папки в корень репозитория (через `git push` или Add file → Upload files; в веб-интерфейсе есть ограничение на размер одного файла, у нас самый большой файл меньше 2 МБ).
3. Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main`, папка `/ (root)` → Save.
4. Через минуту-две сайт откроется по адресу `https://<логин>.github.io/<репозиторий>/`.
5. Вписать этот адрес в `base_url` в `src/site.json`, пересобрать и залить снова — появятся canonical, hreflang и `sitemap.xml`.

Файл `.nojekyll` отключает обработку Jekyll — так GitHub отдаёт файлы как есть.

## Форма заявки

GitHub Pages не принимает данные форм. Пока `form.provider` пустой, форма проверяет поля, собирает текст заявки и предлагает скопировать его и отправить в мессенджер. Чтобы заявки приходили автоматически, подключите один из вариантов:

| Вариант | Что указать в `site.json` | Комментарий |
|---|---|---|
| Web3Forms | `"provider": "web3forms", "access_key": "<ключ>"` | заявки приходят на почту; ключ выдают на web3forms.com |
| Formspree | `"provider": "formspree", "endpoint": "https://formspree.io/f/<id>"` | заявки на почту и в кабинет |
| Свой webhook (n8n, Make) | `"provider": "webhook", "endpoint": "https://.../webhook/..."` | можно отправлять в Telegram, Google Sheets, CRM |

Лимиты бесплатных тарифов у сервисов меняются — проверьте на их сайтах перед подключением. Форма отправляет JSON с полями `name`, `phone`, `work`, `area`, `message`, `lang`, `page`. Если отправка не удалась, посетитель видит сообщение и готовый текст для мессенджера.

## Что нужно заполнить или подтвердить

Данные (сейчас заглушки):
- название бригады; телефон; Telegram / Viber / WhatsApp;
- график работы; зона выезда кроме Минска;
- юридические данные для подвала (ИП/организация, УНП) — зависят от формы регистрации;
- оператор персональных данных и срок хранения заявок в политике конфиденциальности (текст политики стоит показать юристу).

Утверждения в текстах, которые написаны по материалам, но должны быть подтверждены владельцем:
- раздел «Как работаем», особенно пункт «Смета: фиксируем список работ и стоимость до старта»;
- вопросы «Можно заказать только часть работ?» и «Что подготовить к приходу мастеров?»;
- перечень услуг: штукатурка, шпатлёвка и покраска, обои, плитка в санузлах, откосы, декор, подъезды.

Белорусский текст лучше вычитать носителю языка (термины «адкосы», «другаснае жыллё» и т. п.).
